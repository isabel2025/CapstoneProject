# Hardware

The project uses a custom PCB designed around the ESP32-WROOM-32D.

The design includes:

- SHT3x, CCS811 and SPS30 sensor connections
- status LEDs
- buzzer alert circuit
- battery and charging section
- regulated 3.3V and 5V power
- USB programming interface

The PCB was designed in Fusion 360 as a two-layer board and assembled for the final prototype.
